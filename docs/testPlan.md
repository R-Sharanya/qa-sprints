# Functional Test Plan - Swag Labs (SauceDemo)

## 1. Scope of Testing
- **In Scope:** User Authentication, Product Catalog, Cart Management, Checkout Flow.
- **Out of Scope:** Payment gateway integration (mocked), Social media links.

## 2. Test Strategy
- **Manual Testing:** Execution of high-value functional test cases and exploratory testing.
- **Defect Tracking:** Logged via GitHub Issues with standardized bug reports.
- **Test Deliverables:** Test Plan, Test Cases, Requirement Traceability Matrix (RTM), Bug Reports.

## 3. Environment Specs
- **Application URL:** https://www.saucedemo.com/
- **Browsers:** Google Chrome (Latest), Mozilla Firefox (Latest)
- **Devices:** Desktop (Windows 11 / macOS)
